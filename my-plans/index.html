Add Globee to your home screen

Open Globee home in the browser you use for My plans. Then add it to your phone’s home screen.

  • iPhone · Safari Tap Share, then Add to Home Screen. Turn off Open as Web App if shown. The shortcut opens in your default browser.
  • Android · Chrome Tap the three dots, then Install and create shortcut → Create shortcut → Add. Some versions call this Add to home screen.
