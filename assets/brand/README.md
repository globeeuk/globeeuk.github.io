# Globee identity — 9 October 2026

Approved by Yewon for public website branding on 9 October 2026.

`globee-handwriting-v2.png` is an AI-assisted adaptation of the family's original drawing and handwriting samples. The samples did not spell the entire word Globee: the wordmark is reconstructed, not a literal trace. No child names, faces or schoolwork are included in the public asset.

Use the original transparent image with the shared `.brand-art` viewport in `/brand.css`. Do not smooth the linework or substitute a typeset font. The viewport removes empty canvas padding; it does not edit the drawing. Desktop wordmark width: 178px; mobile: 138px (126px on the smallest screens); footer: 130px. Existing masthead heights stay unchanged.

`/favicon.svg` is a simplified code-native small-size version of the asymmetrical drawing, with warm ivory, charcoal and one amber patch. It replaces the former amber G badge.

Both static pages and `seo/build.py` use this shared identity. Future SEO refreshes must preserve the logo, shared stylesheet and cache-versioned favicon. Page copy, region colours and event photography remain unchanged. Instagram profile artwork is maintained privately in the project outputs, not published here.
